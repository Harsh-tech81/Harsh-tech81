# Fixing the broken profile cards

This update fixes the invalid local `tech-stack.svg` / `languages.svg` XML and replaces the fragile public GitHub stats endpoints with SVG cards generated by GitHub Actions.

## Apply the update

Copy the updated `README.md`, `assets/tech-stack.svg`, `assets/languages.svg`, and `.github/workflows/update-readme-stats.yml` into the root of your cloned `Harsh-tech81` profile repository, overwriting the old files.

Then run:

```powershell
git add .
git commit -m "Fix profile SVGs and automate GitHub stats"
git push origin main
```

## Generate the cards once

1. Open the repository on GitHub.
2. Go to **Actions**.
3. Select **Update README statistics**.
4. Click **Run workflow** and confirm.
5. Wait for the workflow to finish. It will create `profile/stats.svg` and `profile/top-langs.svg` and commit them automatically.
6. Refresh your profile page.

The workflow runs daily after the first successful manual run. No personal access token is required; it uses the repository's `GITHUB_TOKEN`.

The contribution streak card remains on its existing provider because it was loading in the supplied screenshots. The broken external activity-graph image has been removed rather than leaving a dead image in the README.
